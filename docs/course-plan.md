# 오픈소스프로그래밍 9–14주차 운영

2026-10-22 수정: 팀 프로젝트와 짝·동료 리뷰 과제를 제외합니다. 학생은 모든 과제를 개인별로 수행하며, 교수자 피드백 또는 공개 Autograder 검사 결과에 따라 수정합니다. 결과와 이해도는 개인별로 확인합니다.

교시당 50분, 주당 실수업 200분이며 쉬는 시간은 별도입니다. 앞의 세 수업에 기초 이론·시연을 집중하고, 뒤의 세 수업은 대부분 실습으로 운영합니다.

## 저장소 구분

- 9–10주차: 본인이 직접 만든 공개 `oss-week09`.
- 11주차: 이 공통 저장소를 Fork하고 원본 main으로 기여 PR. 교수자가 검토·병합합니다.
- 12–14주차: **Use this template**으로 본인 계정에 공개 `oss-individual-labs`를 생성합니다. 각자 같은 시작 코드에서 독립적으로 기능·테스트·배포를 실습합니다. PR 대상은 본인 저장소 main입니다. 팀 저장소·팀 권한·역할 분담은 없습니다.
- 교수자는 12주차 시작 직전 배포 기준 commit SHA를 LMS에 공지합니다. 템플릿 사용 시 그 버전이 포함됐는지 확인하고 수업 중 시작 코드를 임의로 바꾸지 않습니다.

모든 학생의 기본 기능은 `--keyword` 이름 검색으로 통일해 동일한 공개 검사 기준을 적용합니다. 정렬·CSV 내보내기 등은 기본 완료 후 선택 실습입니다. OpenCV는 필수가 아닙니다.

## 검토와 제출

짝 리뷰, 타인 리뷰 URL, 팀 발표·공동 결과물·팀 점수를 요구하지 않습니다. 학생은 PR의 Files changed를 스스로 확인하고, 교수자 피드백이나 Autograder의 실패 항목을 같은 branch에서 고칩니다.

공개 Actions에는 기능별 통과/실패와 오류 정보만 남깁니다. 성적·명단·비공개 평가 메모는 LMS에 둡니다. LMS에는 PR URL, **제출 시점의 전체 commit SHA**, 검사 실행 URL 또는 결과, 실제 명령·출력, 변경 이유를 제출합니다. 교수자 리뷰·병합·워크플로 실행 승인 대기는 학생의 미제출과 구분합니다.
