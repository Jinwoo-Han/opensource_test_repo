# 9~14주차 수업 계획

7주차에 중간고사 대비 Summary를 진행한 진도를 반영합니다. 9주차에 오픈소스 개념·생태계·GitHub 연결을 배우고, Git은 이미 배운 reset/revert 다음인 branch와 협업부터 이어갑니다. OpenCV는 필수가 아닙니다.

교시당 50분, 주당 실수업 200분을 가정합니다. 이론·시연은 9~11주차에 집중하고 이후는 실습 중심입니다. 각 주차에 마지막 10분의 결과 제출·이해 확인을 포함합니다.

## 공개 운영

- 수업 안내·개인 실습·공통 기여·팀 프로젝트를 공개합니다. 학번·성적·개인 연락처·교수자 평가 메모는 LMS/교수자 관리 공간에 둡니다.
- 9~10주차: 학생 개인 저장소. 11주차: 이 저장소의 fork. 12~14주차: 템플릿에서 생성한 팀 저장소.
- 현재 19명 기준 3인 팀 5개와 4인 팀 1개를 기본안으로 둡니다. 편성은 교수자가 안내합니다.
- 작성자·리뷰어·실행 확인자 역할을 순환합니다. 개인별 코드 PR과 타인 리뷰를 남깁니다.
- CI 통과는 기능 확인용 피드백입니다. 커밋·PR 개수만으로 점수를 정하지 않습니다.

## 이어서 만들 프로젝트

`campus_tool`은 가상 캠퍼스 정보를 CSV에서 읽어 조건으로 찾는 작은 Python 프로그램입니다. 함수·파일 입출력을 활용해 검색, 정렬, 결과 저장, 입력 검증을 확장합니다. 라이브 API나 별도 유료 서비스 없이 실습할 수 있습니다.

시각적인 주제를 원하는 팀은 교수자와 범위를 맞춰 Pillow 이미지 일괄 처리 도구를 선택할 수 있습니다. 어떤 주제든 Issue·개인 branch·PR·리뷰·테스트·릴리스라는 완료 기준은 같습니다.
