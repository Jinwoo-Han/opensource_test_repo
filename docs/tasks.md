# 기여 과제

[열린 Issue](https://github.com/Jinwoo-Han/opensource_test_repo/issues)에서 같은 제목을 찾습니다. 코드·문서 과제는 담당자를 확인하고 한 명 또는 한 팀이 맡습니다. **T01은 여러 학생이 각자 다른 파일로 참여하는 반복형 과제**입니다.

| ID | 과제 | 완료 기준 |
|---|---|---|
| T01 | 첫 기여: 가상 장소 CSV 추가 | 별칭별 파일 1개, 1~3행, 기존 자료와 중복 없는 ID, 로컬 실행·테스트, PR, 동료 리뷰 |
| T02 | 이름 부분 검색 `--keyword` | 기존 필터와 함께 동작, 한글·영문 대소문자·결과 없음 테스트, README 예시 |
| T03 | 결과 정렬 `--sort` | `name`/`price` 선택, 동일 값 처리 기준 설명, 기존 순서 기본값 유지, 테스트 |
| T04 | 검색 결과 CSV 내보내기 `--output` | 정확한 헤더·UTF-8, 한글·쉼표·결과 없음 처리, 기존 파일 덮어쓰기 정책을 Issue에서 합의, 테스트 |
| T05 | 중복 ID 오류 메시지 개선 | 중복된 두 파일 위치를 찾을 수 있는 메시지, 재현 테스트, 기존 검증 유지 |
| T06 | CSV 작성과 오류 수정 예시 문서 | 잘못된 열·금액·ID의 최소 예시와 수정 절차, 다른 학생의 재현 확인 |
| T07 | CLI 입력 오류 테스트 보강 | 잘못된 정수 옵션·읽을 수 없는 CSV 등 미검증 경로의 종료 코드/메시지 검증, 기존 테스트와 중복 최소화 |

프로그램은 기본 목록·종류·가격 검색이 정상 동작하는 상태에서 시작합니다. 미구현 기능을 버그라고 부르지 않고 기능 제안으로 다룹니다. 데이터 기여만 한 학생도 팀 프로젝트 단계에서 Python 코드 변경과 리뷰를 수행합니다.

T02~T04는 같은 CLI 파일을 수정할 수 있습니다. 각자 다른 branch를 사용하고, 먼저 병합된 변경을 가져온 뒤 충돌을 해결합니다. 교수자는 작업 난이도와 수강 인원을 보고 배정합니다. 정답 코드가 아니라 **완료 기준**을 보고 구현합니다.
