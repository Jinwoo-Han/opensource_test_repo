# 교수자 리뷰와 학생의 피드백 반영

학생끼리의 PR 리뷰는 과제가 아닙니다. 교수자는 필요한 PR을 검토하고, 객관적인 동작은 Autograder로 확인할 수 있습니다. [자동검사 운영](autograding.md)을 함께 봅니다.

## 교수자 확인 순서

1. LMS의 저장소·PR·제출 SHA를 확인합니다. PR head가 바뀌었으면 마감 제출본과 구분합니다.
2. 목적과 Issue, Files changed, 실제 실행 결과를 읽습니다. 기능 구현 대신 테스트·workflow만 완화한 변경이 있는지도 봅니다.
3. 공통 기여는 `tests` CI, 개인 과제는 해당 주차의 교수자 원본 Autograder 결과를 확인합니다.
4. 입력·관찰 결과·수정할 이유를 구체적으로 남깁니다. 의미 있는 테스트, 설명, 릴리스 첨부물은 별도로 확인합니다.

```text
확인한 제출 SHA:
확인한 변경/입력:
관찰한 결과:
질문 또는 수정 요청:
다음 제출에서 확인할 기준:
```

교수자는 GitHub에서 Comment 또는 적절한 리뷰 상태로 피드백할 수 있습니다. 점수·개인별 평가 메모는 LMS에 기록합니다. 학생은 교수자 의견과 자동검사 실패 내용을 읽고 **기존 PR의 같은 branch**에서 수정·commit·push한 뒤 실제 재실행 결과를 남깁니다.

11주차 원본 main의 병합은 교수자가 담당합니다. 10주차와 12–14주차의 개인 저장소는 교수자가 공지한 검사·검토 기준을 충족한 뒤 학생이 merge commit으로 병합합니다. 개인 저장소에 교수자를 collaborator로 초대하는 것은 필수 조건이 아닙니다. self-approval이나 타인 리뷰 URL도 요구하지 않습니다.

교수자 검토·병합 대기 때문에 제시간에 제출한 PR을 미제출로 처리하지 않습니다.
